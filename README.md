## 🛠️ Em destaque: FinTrack API

Projeto de portfólio que simula uma API de controle financeiro pessoal, com foco em segurança:

- Autenticação JWT (access + refresh tokens) com [Auth0 java-jwt](https://github.com/auth0/java-jwt)
- Spring Security stateless com filtro customizado (`AccessTokenFilter`)
- Proteção contra IDOR via verificação de propriedade dos recursos
- Suporte a transações recorrentes com parcelas vinculadas via `parentTransactionId`
- PostgreSQL + JPA, seguindo princípios de Clean Code
